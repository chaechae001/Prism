# 작업 로그

작업이 끝날 때마다 이 폴더에 `YYYY-MM-DD-담당-작업명.md` 형태로 파일을 추가합니다. 기존 파일을 덮어쓰기보다 작업별로 분리하세요.

```markdown
# 작업명
- 날짜:
- 담당:
- 범위:

## 구현한 기능
- 사용자가 할 수 있게 된 행동을 짧게 설명

## 변경 파일
| 구분 | 경로 | 변경 내용 |
|---|---|---|
| 추가/수정/삭제 | frontend/src/... | 이유 |

## 검증
- 실제 실행 명령과 결과
- 미확인 영역

## 상대 개발자에게
- 공유 API/DB 변경 여부
- 필요한 다음 작업
```

백엔드 담당은 본인의 DB·API 변경을 별도 로그로 남기고, 프론트 담당은 화면 변경을 별도 로그로 남깁니다. 상대 로그는 본인 작업으로 수정하지 않습니다. API 필드 변경은 로그만으로 합의되지 않으므로 변경 이유와 요청/응답 예시를 먼저 공유하세요.
