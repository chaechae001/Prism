# 저장된 군집 결과 미리보기

저장된 분석 결과를 기존 뉴스 API와 화면에 연결합니다. 이 실행 방식은 `.env`와 DB 접속 정보를 읽지 않으며 수집·모델 추론·LLM 호출을 실행하지 않습니다.

| 데이터 | 원문 기사 | 대표기사 후보 | 카테고리 | 출처 |
|---|---:|---:|---|---|
| scheduled-sbs | 29 | 20 | 경제 | SBS |
| anchor92 | 92 | 74 | 정치·경제·사회 | SBS |

두 스냅샷은 중복 기사가 있을 수 있어 합산하지 않습니다. 둘 다 SBS 자료이므로 언론사 간 관점 다양성 평가용 데이터가 아닙니다. 기술 카테고리나 다른 언론사 데이터는 추가 입력이 필요합니다. 대표기사 제목은 원문 제목이며 가치중립적으로 재작성된 제목이 아닙니다.

## 실행

프로젝트 루트 터미널에서 실행합니다. 기본 백엔드 의존성만 필요하며 분석 모델 설치는 필요하지 않습니다.

```powershell
python -m pip install -r backend/requirements.txt
./scripts/run-cluster-preview.ps1
```

다른 터미널에서 프론트를 실행합니다.

```powershell
cd frontend
$env:VITE_API_BASE_URL='http://127.0.0.1:8006'
npm.cmd run dev:http -- --port 5186
```

`http://127.0.0.1:5186/`에서 확인합니다. 서버를 재시작할 때 `-Dataset anchor92`를 지정하면 74개 대표기사 후보를 볼 수 있습니다. 기본 데이터로 돌아가려면 `-Dataset scheduled-sbs`를 사용합니다. 프론트는 새로고침합니다.

```powershell
./scripts/run-cluster-preview.ps1 -Dataset anchor92
```

Ctrl+C로 실행한 서버를 종료합니다. 실행 스크립트는 종료 시 변경한 프로세스 환경변수를 복원합니다. 환경 파일은 변경하지 않습니다.

## 표시와 호환성

- 기존 목록·상세·카테고리 API 경로와 응답 구조를 유지합니다.
- `Article.image_url`만 선택 필드로 추가했습니다. 사진 없는 기존 기사도 유효합니다.
- 대표기사 본문 앞 240자까지만 발췌합니다. AI 요약은 `pending`이며 생성된 요약 문장이나 검증된 관점을 만들지 않습니다.
- 원문 ID·링크를 유지하고 대표기사를 출처 목록 첫 번째에 둡니다. 실제 뉴스에 가상 예시 사진을 붙이지 않습니다.
- 브라우저는 공개 사진 URL을 직접 표시합니다. 사진 서버 오류 시 기본 이미지로 대체합니다.
- 스토리·카테고리·사진 탐색·상세·북마크 UI는 동일한 데이터 어댑터를 사용합니다. 군집 미리보기의 유료 AI 대화는 비활성화합니다.
- 잘못된 본문 해시나 군집 연결은 오류로 처리하며 가상 뉴스로 바꾸지 않습니다. 이미지 정보만 실패하면 기사와 원문 링크는 유지합니다.

## 검증과 확장

`backend/tests/test_clustering_snapshots.py`는 두 스냅샷의 파일 해시, 기사 수, 대표기사 수, 페이지 조회, 상세, 카테고리와 검색을 확인합니다. DB 저장·조회 검증은 `PRISM_TEST_DATABASE_URL`로 명시한 폐기 가능한 로컬 `prism_test` DB에서 실행합니다.

새 입력 분석은 [군집 분석](CLUSTERING_HANDOFF.md), DB 배치 저장은 [군집 저장](CLUSTER_STORAGE.md), 정기 수집은 [수집 작업자](SCHEDULED_NEWS.md)를 참고합니다. 저장된 결과 조회와 모델 재학습·재분석은 별도 단계입니다.
