# PRISM — Editorial UI v2

2026-10-22 · 정채은 프론트/UI 작업. 실제 코드에 적용한 디자인 기준입니다.

## 방향

‘여러 출처를 함께 읽는 편집된 뉴스 지면’을 목표로 합니다. 상단 안내와 캘린더의 면적을 줄이고, 제목 → 사건의 맥락 → 보도 매체 → 쟁점 비교 → 상세 읽기 순서로 정보를 배치했습니다. 첫 번째 사건은 더 큰 제목과 IN FOCUS 표시로 구분합니다.

이전 버전은 동일한 연보라 박스·작은 보조 글자·장식 그림이 반복되었습니다. v2에서는 따뜻한 종이색 바탕, 짙은 잉크색 제목, 제한된 보라색, 출처 묶음의 연두색을 사용합니다. 색상은 정치 성향이나 편향 점수를 뜻하지 않습니다.

레퍼런스의 로고·사진·상용 UI 파일을 복제하지 않았습니다. ‘모든 최신 앱의 공통 트렌드’라는 통계적 주장이 아니라, 해당 참고 자료를 보고 이 서비스에 맞춰 선택한 디자인입니다. Figma 프로젝트 파일을 생성한 작업은 아닙니다.

## 색상과 글자

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| Canvas | `#F6F5F0` | 따뜻한 미색 배경 |
| Paper | `#FFFEFA` | 사건 카드·상세 읽기 |
| Ink | `#29232F` | 헤드라인·본문 주요 정보 |
| Primary | `#544062` | 읽기 버튼·활성 탭·브랜드 |
| Lilac | `#EAE5EF` | 선택 표시·보조 브랜드 면 |
| Source | `#F0F2E8` | 여러 출처 묶음의 바탕 |
| Lime | `#DCE8BC` | 탐색 CTA·활성 메뉴의 작은 포인트 |
| Line | `#E4E1DC` | 정보 구획·카드 경계 |

- 한글·기본 글꼴: Pretendard Variable. 공식 v1.3.9의 글꼴과 OFL 라이선스를 `frontend/public/fonts/`에 포함했습니다. 출처: [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard).
- 제목 위계: PC 페이지 제목 38px, 모바일 30px. 대표 사건은 PC 30px/모바일 25px, 일반 사건은 24px/21px입니다. 320px에서는 각각 23px/20px입니다.
- 본문: PC 14px/모바일 13px, 행간 약 1.85. 짧은 카드에는 요약 첫 문장을, 상세에는 전체 요약을 표시합니다.
- 주요 읽기 버튼 44px 이상, 하단 메뉴 버튼 56px. 검색 입력은 모바일 16px로 모바일 브라우저의 자동 확대 가능성을 줄였습니다.
- 기능을 나타내는 색상·크기 외에 키보드 포커스, 선택 탭 상태, reduced-motion 대응을 유지했습니다.

## 서비스만의 표현

1. **겹치는 세 면의 심벌**: 서로 다른 출처가 같은 맥락에서 만난다는 의미로 직접 작성한 SVG입니다.
2. **출처 묶음**: 실제 응답의 매체 수와 이름의 첫 글자를 이용합니다. 가짜 로고·중립 점수·분석 성공률을 만들지 않습니다. 누르면 해당 사건의 출처 탭으로 이동합니다.
3. **읽기 순서가 있는 카드**: 메타 정보·제목·맥락·출처·쟁점·읽기 버튼을 일관된 순서로 배치합니다. 대표 카드에만 쟁점 설명을 펼쳐 정보 밀도를 조절합니다.
4. **마이페이지**: 모바일에서는 실제 열람 기록·주제 분포가 먼저 보입니다. 밸런스 점수 미연결 상태와 예시 점수 구분은 유지합니다.
5. **모바일 상세**: 전체 화면에 가까운 하단 시트, 충분한 제목/본문 간격, 출처로 이어지는 인용 버튼. 닫기·포커스 관리는 기존 Radix UI를 유지합니다.

RSS 미리보기의 원문 제목은 AI 중립 제목이 아닙니다. AI 분석 전·가상 자료·미검증 표시는 유지하며, 요약이 없으면 생성된 것처럼 보이지 않도록 원문 확인을 안내합니다.
