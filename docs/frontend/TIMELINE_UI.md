# 타임라인 UI v2 — 프론트엔드 연결 범위

기준일: 2026-10-21. 사용자가 제공한 러프 이미지는 날짜 탐색·세로 사건 카드·요약·관점 비교·모바일 메뉴의 정보 구조를 참고하는 데 사용했습니다. 이미지에 등장하는 뉴스 제목·사진·날짜·정확도 수치·주장 자체는 콘텐츠로 사용하지 않았습니다.

## 구현한 화면

- 타임라인(기본): 사건 업데이트 날짜별 그룹, 7일 탐색, 날짜/기간 선택.
- 오늘의 요약: 기존 추천 순위로 브리핑, 모바일 탐색 폭 조절.
- 카테고리: 정치·경제·사회·기술 주제 선택과 기존 API 필터.
- 보관함: 기존 localStorage 북마크를 유지. 일부 사건 조회가 실패해도 나머지는 표시.
- 사건 상세: 요약·관점·출처 탭. 카드의 CTA 목적에 맞는 탭을 바로 열기.
- 모바일: 고정 하단 메뉴와 한 열 카드. PC: 타임라인+발견/분포 사이드 패널.

디자인은 밝은 회청색 바탕, 블루 주요 액션, 여백 있는 카드, 쟁점 비교의 청록/앰버 보조색을 사용합니다. 색상은 정치 성향이 아닌 주제/정보 구분을 뜻합니다. Radix Dialog·Tabs·Slider, Lucide, TanStack Query를 유지하며 새 패키지는 설치하지 않았습니다.

## 정보 표시 원칙

1. 기사 수·출처 수·요약·관점은 API 실제 필드만 사용합니다. ‘관심도 98%’ 같은 임의 점수는 만들지 않습니다.
2. 날짜는 `story.updated_at`을 `Asia/Seoul`로 변환합니다. 실제 발행일이나 사건 발생일과 혼동하지 않도록 ‘업데이트 날짜’로 표시합니다.
3. 뉴스가 없는 날에는 실제로 빈 화면을 표시합니다. 현재 fixture는 10월 21일 하루의 사건 12개이며 과거 뉴스를 임의 생성하지 않았습니다.
4. 사진은 RSS 응답에 있다고 자동 게시하지 않습니다. 현재 카드 그림은 기존 직접 작성 SVG이며 실제 보도 사진이 아닙니다.
5. is_demo/label_status에 따라 상세의 가상·미검토·검토 표시를 달리합니다. 실제 언론사 이름도 첫 글자 아바타로 처리합니다.
6. 피드백 성공 문구는 응답의 persisted 값을 따릅니다. 저장하지 않은 응답을 저장 완료라고 표시하지 않습니다.

## 현재 API와의 관계

API 요청/응답 스키마·엔드포인트·생성 타입은 이번 작업에서 변경하지 않았습니다.

| 기능 | 처리 위치 | 제약 |
|---|---|---|
| 검색·카테고리·정렬·다양성·더 보기 | 기존 GET /api/v1/stories | 기존 쿼리를 그대로 사용 |
| 상세/관점/출처 | 기존 GET /api/v1/stories/{id} | panel은 프론트 UI 상태 |
| 날짜/기간 | 프론트에서 현재 로드한 목록 필터 | 서버 전체 아카이브 검색 아님 |
| 출처·카테고리 분포 | 화면에 표시한 목록으로 계산 | 전체 데이터/개인 성향 평가 아님 |
| 북마크 | localStorage prism:v1:saved | 로그인/기기 간 동기화 아님 |

날짜 필터가 걸린 상태에서도 ‘더 많은 이야기 불러오기’를 눌러 다음 API 페이지를 읽을 수 있습니다. API 전체 수와 로드한 수를 따로 표시합니다. 그룹 내 순서는 선택한 추천 순위를 유지하고, 날짜 그룹만 최신 날짜부터 정렬합니다. ‘최신순’을 선택하면 그룹 내에서도 최신순으로 보입니다.

## URL 상태

기존 q/category/mode/diversity/story 상태를 유지하고, 프론트 전용 상태를 추가했습니다.

- view: timeline(default) / briefing / categories / saved
- date: YYYY-MM-DD, 단일 업데이트 날짜
- from/to: YYYY-MM-DD, 양끝을 포함하는 업데이트 날짜 범위
- panel: summary(default) / perspectives / sources

이 값은 새 백엔드 파라미터가 아닙니다. `frontend/src/api/client.ts`는 그대로 유지했으므로 서버에 date/from/to/panel을 전달하지 않습니다.

## 파일별 역할

- `frontend/src/App.tsx`: 전체 레이아웃과 화면 조합.
- `frontend/src/hooks/useNewsWorkspace.ts`: URL·API 조회·필터·북마크 상태.
- `frontend/src/presentation/timeline.ts`: 한국 시간 날짜·기간 필터·그룹화.
- `frontend/src/components/DateNavigator.tsx`: 7일 탐색·기간 선택 Dialog.
- `frontend/src/components/TimelineCard.tsx`: 사건 카드·요약·관점 미리보기.
- `frontend/src/components/StoryDetail.tsx`: 기존 상세를 개선, 시작 탭·표시 조건·포커스 복귀.
- `frontend/src/styles.css`: 반응형 디자인 토큰과 스타일.

## 백엔드와 연결할 때

기존과 같이 `VITE_API_MODE=http`와 서버 origin을 설정합니다. 팀원이 동일 API 계약으로 가상 사건 1개+기사 3개를 반환하면 수정한 화면에서 그대로 표시할 수 있습니다. 현재 UI는 피드백·카테고리 API도 기존 계약대로 호출하므로 팀원은 미구현 엔드포인트 여부를 알려주세요.

서버 기간 검색·이미지 URL·RSS 입력 모델은 `RSS_SCHEMA_REVIEW.md`의 다음 계약 변경 후보를 먼저 합의한 뒤 추가합니다. 해당 기능이 이번 작업으로 완성된 것처럼 취급하지 않습니다.
