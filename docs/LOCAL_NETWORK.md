# 다른 기기에서 개발 화면 확인하기

개발 PC와 휴대폰 또는 다른 PC를 같은 공유기에 연결합니다. 개발 PC가 유선이고 휴대폰이 와이파이여도 같은 내부망이면 사용할 수 있습니다.

## 실행

기존 API를 `127.0.0.1:8005`에서 실행한 상태로, `frontend` 폴더의 PowerShell에서 다음 명령을 실행합니다.

```powershell
ipconfig
npm.cmd run dev:lan -- --host <개발_PC의_IPv4_주소>
```

다른 기기의 브라우저에서 `http://<개발_PC의_IPv4_주소>:5185/`를 엽니다. 다른 API 포트를 쓰는 경우 실행 전에 `$env:PRISM_LAN_API_TARGET='http://127.0.0.1:포트'`를 설정합니다.

LAN 전용 Vite 설정은 브라우저의 `/api` 요청을 로컬 API로 전달합니다. 따라서 휴대폰이 자신의 `127.0.0.1`로 API를 요청하지 않습니다. API 포트를 외부에 열거나 CORS 허용 대상을 추가할 필요도 없습니다. 기존 `dev`, `dev:http` 실행 방법은 유지됩니다.

## 확인 및 주의사항

- PC를 켜 두고 API와 화면 서버를 모두 실행해야 합니다.
- 접속되지 않으면 같은 내부망인지, 게스트 와이파이인지, Windows 방화벽에서 Node.js의 해당 사설망 접속이 허용됐는지 확인합니다. 방화벽 전체를 끄지는 않습니다.
- 게스트 와이파이·기관 네트워크는 기기 간 접속을 차단할 수 있습니다.
- 북마크·댓글·DM 목록 등 로컬 저장 기능은 기기와 접속 주소별로 별도 보관됩니다.
- 개발 검증용이며 신뢰하는 내부망에서 사용합니다. 인터넷 공유용 배포나 공유기 포트 포워딩 설정은 아닙니다.
- 종료는 실행 터미널에서 `Ctrl+C`를 누릅니다.
